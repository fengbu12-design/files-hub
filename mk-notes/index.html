按剩余时间选路线

同一个材料库，三种走法；不知道从哪开始就先看 A
A
只剩两天：先做真题最省时间的顺序
  1. 先把 16 道练习自己写一遍，写完再点开答案对判分点
  2. 背 总复习 §7 的四张表（T8 6×5 / T9 8×7 / T10 九情形 / 三种粘性）
  3. 把笔记里 34 条红色徽标（老师亲手划的）逐页过一遍：从 T6、T7、T8 的一览卡进
  4. 最后看 总复习 §8 三套答题模板，背句型而不是背答案
B
还有五到七天：按讲补每天两讲，配总复习兜底
  1. 第一天只做两件事：总复习的 §1 三块大陆 + §2 八模型对照表
  2. 之后每天两讲：先看该讲「速览 + 图」，再逐页看，最后做讲末自测（答案折叠）
  3. 补完 T4–T7 那天，回头读 §5「消费函数被装配七次」——这四讲其实只改了它一次
  4. 考前两天切到路线 A 的第 1、2 步（练习 + 四张表）
C
从头补：十天以上按大陆推进，别按页码
  1. 第一块 T1→T3：增长事实、索洛、跨国差异（一条资本积累式串完）
  2. 第二块 T4→T7：两期消费、禀赋经济、财政、生产经济（都在装配同一条消费函数）
  3. 第三块 T8→T10：两条曲线、货币进来、价格粘住（同一个需求侧，三个供给侧）
  4. 每讲收尾都用 §9 的 24 问自测验一遍，答不上来说明该回哪一节
