两条硬约束（以后想再挪目录，先看这两条）：

1. **公式引擎是外链引用的**（`<script src="./_mathjax_tex_svg.js">`），所以它必须和那 12 个页面待在同一个目录里。
2. **页面之间互相链接用的是裸文件名**（`Topic 5 笔记.html`），所以 12 个页面必须始终同层；只有 `index.html` 在上一层，从内容页回主页走 `../index.html`。

> 路径不要手写。所有脚本都从 `构建/paths.py` 取路径，写新脚本时 `import paths as P` 即可。
> 改完目录跑 `python paths.py` 能看到一份体检表（哪一项找不到会标 `!!`）。

> `课程笔记模版/` 保持原样不动，只作母版参考。本目录是它的「宏观课」专用副本。

### Topic 6 · 财政政策与李嘉图等价（20 页，1.4 MB）

这一讲在 Topic 5 的禀赋经济里**加进一个政府**，然后只做一件事：**把政府的两期预算代进家庭的两期预算**。代完之后 **`T` 与 `B` 全部消失**，消费函数从 `C^d(Y_t, Y_{t+1}, r_t)` 变成 `C^d(Y_t − G_t, Y_{t+1} − G_{t+1}, r_t)`。整讲的结论就挂在这个「税消失」上。

- **8 个小节、20 页逐页精讲，每页都有「💬 白话」**；**2 张图配「📊 这张图怎么看」**（p18 `G_t↑`：双箭头拆解 + IS 右移；p19 `G_{t+1}↑`：支出线下移 + IS 左移）——两张都写清了上下两图的轴、每条线的原名/新名标注（`G_{0,t}` / `G_{1,t}`）、**一对反向小箭头**（蓝 = 政府多花的 `dG`、绿 = 家庭因税负少花的 `MPC·dG`）、读图三步与考法；
- **开头符号表**（四组：政府的四个量、家庭的四个量、模型参数、图上带角标的点）+「读方程的四个动作」（谁在决策 → 哪条约束被换掉 → 什么消失了 → 剩下谁定谁）；
- **13 处「⚖️ 等式两边」**（政府两条流量约束、政府 IBC、家庭两条约束、家庭 IBC、含税消费函数、减税 1 块的账（用 `\underbrace` 拆成两半）、出清 `S−B=0`、商品出清、乘数 1、乘数 `1/(1−MPC)`、轮次两式、完全挤出）、**17 页共 60 个「🔍 逐符号拆解」**；
- 关键补讲：① **为什么「减税 1 块」家庭会先存下 `MPC`、再花掉 `1−MPC`**——这两笔合起来正好抵消，是理解 RE 的唯一算术；② **政府 IBC 与家庭 IBC 为什么「同构」**（都是「现值支出 = 现值收入」，只是一个用 `T`、一个用 `Y`）；③ **出清为什么是 `S − B = 0` 而不是 `S = 0`**（上一讲没有政府，这一讲政府要发债）；④ **三个乘数 1 / `1/(1−MPC)` / 0 的四个格子怎么填**，以及它们各自「关掉了哪个开关」；⑤ **「乘数为零不是李嘉图等价的功劳，而是禀赋经济的功劳」**——课件原话 `Not a consequence of Ricardian equivalence, but rather due to assumption of endowment economy where output cannot respond`，这是全讲最高频的扣分点，笔记里单独用一整页拆这句话；
- **3 张总表**：**政府 vs 家庭的两套预算对照**（六个维度逐行对比，含「为什么能消掉中间变量」）、**三个乘数其实是四个格子**（有/无 RE × `r` 固定/内生）、**李嘉图等价的四个假设：破了会怎样**（每个假设各配「破了以后哪个机制接管」）；
- **公式速查** 20 条 ｜ **概念速查** 33 行 ｜ **易错清单** 16 组 ｜ **自测** 10 题

### Topic 7 · 生产经济中的均衡（24 页，3.0 MB）

### 两个「讲明白」用的块

**① `lr`（⚖️ 等式两边各是什么）** —— 每个公式页必写。一个 list，每项一个等式：

```python
lr=[
  dict(name="t 期预算约束：钱花到哪去 ＝ 钱从哪来",
       lhs="P_tC_t+P_tS_t+M_t",          # 左边（裸 LaTeX，不用包 span）
       lhs_t="今天的三个用途：消费＋储蓄＋现金",
       rhs="P_tw_tN_t-P_tT_t+P_tD_t",    # 右边
       rhs_t="今天的三个来源：工资−税+股息",
       why="每一美元都有去处，所以两边必然相等。"),
]
```

- `lhs` / `rhs` **直接写 LaTeX**，引擎自动套 `\( … \)`（与 `dec` 不同，这里不要包 `<span class='mj'>`）
- 可选 `rel="＋"`（默认 `＝`）、`why_t="两股力量在拔河"`（默认「为什么两边相等」），用于 HP 滤波那类「不是等式」的式子
- 一页有多个等式就放多项，自动编号成一块一块

**② `dec`（🔍 逐符号拆解）** —— 左边一个符号、右边一句人话，`[(符号, 解释), ...]`。
`lr` 回答「这个式子整体在说什么」，`dec` 回答「每个符号念什么」。两个都写最好，只写一个也行。

### ③ `fig`（📊 这张图怎么看）—— **凡是课件页上有图，这一块必写**

> 这条是硬要求。考试里的图题（「看图回答」「这张图说明了什么」）扣分最狠，
> 学生自己盯图看不出重点是常态。宁可文字少一点，图必须讲透。

```python
fig=[
  dict(name="货币市场均衡图（Money Market Equilibrium: Graph）",       # 图名，最好带课件英文标题
       axes=[("横轴", "M_t", "名义货币量，单位是<b>美元</b>"),
             ("纵轴", "P_t", "物价，单位是<b>美元／单位商品</b>")],
       marks=[("M^s", "那条竖直的黑线：货币供给，与物价无关，所以是竖的"),
              ("P_tM^d(r_{0t}+\\pi^e_{t+1},\\,Y_{0t})", "向右上的黑线：名义货币需求"),
              ("(M_{0t},\\,P_{0t})", "交点：唯一同时满足供求的物价")],
       read="先看竖线、再看斜线，交点向左读得物价。",
       exam="最常被问：需求曲线为什么向上？因为横纵轴是 (M, P) 而非常见的 (Q, P)。"),
]
```

- `axes` 每项 `(轴名, 变量, 含义与单位)`；`marks` 每项 `(图上元素, 它是什么)`
- **标签字段（`axes` 的第 2 项、`marks` 的第 1 项）不含中文就自动排成公式，含中文就当普通文字**。
  所以标签里只写数学（`M_t`、`Y^{s\\prime}`、`1950\\text{--}2015`），中文说明一律放描述列。
- 描述字段是 prose：要公式就包 `<span class='mj'>`，或直接用 `<sub>/<sup>`
- `read` = 眼睛该往哪看、按什么顺序看；`exam` = 这图会怎么考、标准答法一句话是什么

**写图的三条自检**（缺一条就说明没讲透）：
1. **坐标轴说清楚了吗**——横纵轴各是什么、单位是什么、往上往右代表什么；
2. **图上每个元素都点名了吗**——每条线、每个交点、每条虚线、灰竖条是什么；
3. **给了「怎么读」和「会怎么考」吗**——只描述图长什么样是不够的，要给出读图动作和答题模板。

## 五、公式写法

```python
add(7, kp="<span class='mj'>Y=AK^{\\alpha}L^{1-\\alpha}</span>")
```

- 用 `<span class='mj'>…</span>` 包住；**Python 源码里 LaTeX 反斜杠写双份**
- 脚本统一把它转成 `\( … \)` 交给 MathJax
- 稳妥命令：`\frac` `\sqrt` `\sum` `\int` `\alpha` `\beta` `\mu` `\sigma` `\hat` `\bar` `\approx` `\Delta` `\ln` `\left( \right)` `\text{…}` `\Rightarrow`
- 避免 `\xrightarrow` `\underbrace` 之类需要额外扩展包的命令

> 内容里的 HTML 是**原样输出**的（不转义），所以可以用 `<b> <br> <i> <span>`；
> 但要写 `&lt;` 代替 `<`，且不要在 `<span class='mj'>` 里面再套 span。

> **公式里不要夹中文**（含全角标点 `，：（）：`）。`\( … \)` 内部只放数学符号，中文写到相邻的说明里。
> 离线 MathJax 对 CJK 字形依赖系统字体，塞进公式容易变方框或宽度错乱；真要用，最多写 `	ext{const}` 这类英文。
> 构建自检会扫「公式之外裸露的 LaTeX」，但**不会**替你检查「公式之内夹了中文」，这条要自己守。

**`📊 这张图怎么看` 的标签可以中英混排**（v3 起）：

```python
marks=[("LM(M_{0,t},P_{0,t})（黑，左上）", "说明……"),   # 混排：公式自动包，中文保持文字
       ("r_t\\times Y_t", "纯 ASCII：整段当公式")]
```

构建时会把标签里「像公式」的 ASCII 片段（含 `^` `_` `\` `{` `}` 且含字母）自动包进 `\( … \)`，中文部分原样保留——
所以不用手写 `\(`。两条禁忌：**小于号写 `&lt;`**（否则被当成 HTML 标签）、**不要在标签里再写 `\(`**（会重复包裹）。

## 六、站内跳转

凡是「见后面某表」「见第 29 页」「下一讲会讲」这类话，都写成链接，别让读者自己翻：

```python
"完整表格见 [[xt1|定性效应总表]]"          # 本讲总表
"与 [[p10|第 10 页]]的总量图对比"          # 本讲某一页
"回忆 [[T1#p12|Topic 1 第 12 页]]"         # 别的讲（同目录 HTML）
"这一条直接通向 [[T10|Topic 10]]"          # 还没做的讲次
```

| 写法 | 目标 |
|---|---|
| `[[p29\|文字]]` | 本讲第 29 页 |
| `[[xt2\|文字]]` | 第 2 张总表（`EXTRA_TABLES` 按顺序 xt1、xt2…） |
| `[[notation\|…]]` `[[formulas\|…]]` `[[summary\|…]]` `[[pitfalls\|…]]` `[[quiz\|…]]` | 符号表 / 公式速查 / 概念速查 / 易错清单 / 自测 |
| `[[T3\|文字]]`、`[[T1#p12\|文字]]` | 别的讲（自动加 `Topic N 笔记.html` 前缀） |

- 目标文件**不存在**时（比如 Topic 10 还没做），自动降级成灰色虚线的 `xref-off` 占位，鼠标悬停提示「这一讲的笔记还没做」——不会变成死链。
- 链接后面会自动带一个小箭头 ↗，一眼能看出可点。
- 构建结束会自检：**所有站内锚点找不到目标都会报错**，`[[` 没解析完也会报错。
- `EXTRA_TABLES` 的 `title` / `sub` / `note` 也会解析 `[[ ]]` **和** `<span class='mj'>`（走 `_rt()`），所以总表的副标题里可以直接写「用 [[p18|第 18 页的五步法]] 现场推」。表格单元格目前按原样输出（只放符号与 `<b>`，不放链接）。

## 七、常见问题

- **公式显示成源码**：检查 `<span class='mj'>` 是否成对，以及 `build_notes.py` 里是否仍是单反斜杠 `"\\("`。
- **图片不显示**：先跑 `make_slides.py`；右下角会标「本页无对应图片」。
- **HTML 换了文件夹后公式失效**：`_mathjax_tex_svg.js` 必须与 HTML 同目录（相对路径 `./_mathjax_tex_svg.js`）。
- **锚点跳偏**：已通过给 `<img>` 写死宽高 + MathJax 就绪后重定位解决，别删那两段脚本。
- **想把某张表加进某一讲**：在 content 文件里写 `EXTRA_TABLES = [{...}]`，重新 `python build_notes.py N` 即可，会自动排到「公式速查」之后并加进右侧目录。
- **本机验证渲染**：浏览器窗口不可见时，可用无头 Chrome 截图：
  `chrome --headless=new --window-size=1280,950 --virtual-time-budget=12000 --screenshot=out.png "file:///…/Topic 9 笔记.html"`

## 八、总复习怎么改

```bash
python build_review.py
```

读 `review_content.py` → 写 `期末总复习.html`。**不依赖 JPG / PDF**，只依赖同目录的 `_mathjax_tex_svg.js`（公式）与十个 `Topic N 笔记.html`（跨讲跳转）。

`review_content.py` 的结构：

```python
COURSE / TITLE / SUBTITLE / META   # META 是字符串列表，显示成首页的胶囊标签
OPENER = [(标题, 正文, 标签), ...]  # 首页三张卡
FLOW   = [dict(num=, title=, desc=, tag=), ...]   # 八节点模型进化链
SECTIONS = [dict(id="s1", num="一", title=..., sub=..., blocks=[...]), ...]
```

`blocks` 里每一块是 `(类型, 内容)`，支持十二种：

| 类型 | 写法 | 说明 |
|---|---|---|
| `p` | `("p", "正文")` | 普通段落 |
| `big` | `("big", "重点句")` | 左侧蓝框大字块 |
| `ul` / `ol` | `("ul", ["条目", ...])` | 无序 / 有序列表 |
| `warn` / `tip` / `note` | `("warn", "小标题", "正文")` | 红框 / 橙框 / 灰框 |
| `table` | `("table", dict(...))` | 见下 |
| `cards` | `("cards", [dict(title=, sub=, body=), ...])` | 卡片网格（窄屏自动换行） |
| `steps` | `("steps", [(标题, 正文), ...])` | 带编号圆圈的步骤块，**每块从 1 重新编号** |
| `eq` | `("eq", [(名称, tex, 说明, 出处), ...], "末尾说明")` | 公式块，`tex` 是**裸 LaTeX**，自动套 `\[ … \]` |
| `raw` | `("raw", "<div>…</div>")` | 直接塞 HTML，不处理 |

`table` 的键：`caption` / `header` / `rows` / `note` / `cls` / `first_bold`。
`rows` 里放**字符串**表示分组行（自动 `colspan` 到底）；`cls="table ctr"` 让单元格居中（适合 +/− 表），`cls="table pit"` 是三列辨析表配色（列 1 蓝、列 2 红、列 3 绿）。

三个能省事的写法：

- `**强调**` → `<b>强调</b>`（引擎自动转，不用敲标签）
- `[[s3|§3 模块一]]` → 跳本节（**不带** ↗ 箭头）；`[[T7#p9|Topic 7 第 9 页]]` → 跳回原讲并带 ↗
- 表格单元格里 `<span class='mj'>Y_{t}</span>` → 行内公式；**整格包裹**

> ⚠️ 一个坑：`<span class='mj'>` 的处理方式是「把该字符串里**所有** `</span>` 换成 `\)`」，
> 所以**同一格里不要同时出现 `<span class='pj'>`（小字）和 `<span class='mj'>`**，
> 否则小字那格的闭合标签会被误伤。需要小字就单独放一格，或改用 `<br>` + 普通文字。

自检（构建后跑一遍）：

```bash
python -c "

print('mj 残留', h.count(\"<span class='mj'>\"), '| ** 残留', len(re.findall(r'\*\*',h)))
bad=[m for m in re.findall(r'href=\"(Topic \d+ 笔记\.html)#([^\"]+)\"',h)
     if 'id=\"%s\"'%m[1] not in open(m[0],encoding='utf-8').read()]
```

## 九、练习页怎么加题（期末练习还在更新）

老师的 `final_practice.pdf` 会加题，所以练习页按「一题一个 dict」写，**加题不动引擎、也不丢进度**。

### 三步

1. 把新 PDF 覆盖 `final_practice.pdf` → 抽文本：
   ```bash
   sh "<workbuddy-pdf skill>/scripts/run.sh" "final_practice.pdf" "out.md" -f md -q
   ```
2. 在 `practice_content.py` 的对应 `SECTIONS.append(dict(...))` 里加一个 item。
3. `python build_practice.py` → 覆盖 `网页/期末练习.html`。

### item 的字段

| 键 | 必填 | 说明 |
|---|---|---|
| `tag` | ✓ | 小问号 `"a"`…`"h"`，决定卡片的 `(a)` 与跳转锚点 `q3f` |
| `q` | ✓ | **题干英文原文**，照抄，别改写 |
| `qcn` | | 题干中文（一句话） |
| `ask` | | 「这题在考」——判分点在哪（红条） |
| `steps` | | `[(小标题, 正文), ...]`，解题分步 |
| `fig` | | `practice_svgs` 的键，或键的**列表**（如 `["is_ys_shift", "cross45_shift"]`） |
| `en` / `cn` | | 参考答案英文 / 中文对照（都进折叠区） |
| `points` | | 判分点列表 |
| `trap` | | 常见失分（⚠ 红框） |
| `refs` | | `[("T8#p21", "Topic 8 第 21 页"), ...]` 回看链接 |

进度存在浏览器 `localStorage` 的 `af5638_final_progress_v1` 里，键是 `qid`（如 `q2g`）。**加新题不会清掉旧勾**；顶部三个按钮是「展开全部答案 / 折叠全部答案 / 清空进度」。

### 三张 SVG 的两种版本

`practice_svgs.py` 里每个图函数都有 `shift` 参数，注册成两个键：

| 键 | 画什么 | 用在哪 |
|---|---|---|
| `is_ys` / `cross45` | 只有两条线（原状） | 「画出 IS 与 Y^s」这种**作图题** |
| `is_ys_shift` / `cross45_shift` | 加冲击后的线、两个交点、①② 箭头 | 「G 上升会怎样」这种**比较静态题** |
| `main4` | 四宫格（劳动市场 / 生产函数 / (r,Y) / 45°） | Q3 主图题 |

> ⚠️ SVG 的 `<text>` 里**不能用 `<sub>/<sup>`**：HTML 解析器遇到它们会「跳出 SVG 命名空间」，结果所有文字失去坐标、全挤到左下角。
> 上下标一律用 `sub()` / `sup()` 这两个函数（内部是 `<tspan dy font-size>`）。
>
> ⚠️ 标签**别压在线上**，也别两个标签贴在一起。加完一个 `T()` 先想「这块地方空不空」——
> 45° 图里那条 `x=Ȳ` 的竖直虚线是最容易被文字压到的地方。

### 构建自检（`build_practice.py` 末尾）

六项：站内死链 / `[[` 残留 / `mj` 残留 / `**` 残留 / 裸露 LaTeX / **JS 语法**。最后一项是用 `node --check` 真的去解析脚本——
因为一个多余的括号会让整段 JS 静默失效（页面能打开，但进度条永远 `0/0`、按钮全死），肉眼极难发现。

## 十、考点标注（EXAM）

十讲笔记的**每一页卡片顶部**多了一条红色徽标，本讲开头多了一张「🎯 本讲考点一览」。数据来自各 `content_topicN.py` 末尾的 `EXAM`：

```python
EXAM = {
    21: [{"k": "final", "t": "↑<span class='mj'>G_{t}</span>：IS 右移、竖线不动 ⇒ r↑、Y 不变", "ref": "q2g"}],
}
```

| 键 | 取值 | 含义 |
|---|---|---|
| `k` | `final` / `mid` / `must` | 期末练习 Key Concepts（老师亲手划，红）／期中练习 Key Concepts（橙）／我横向整理判断的必背项（紫） |
| `t` | 任意 | 这一页的考点，一句话；行内公式用 `<span class='mj'>` |
| `ref` | `q2g` 这种 | 可选。生成「对应 Q2(g)」并链到 `期末练习.html#q2g` |

`build_notes.py` 会把它们渲染成两处：页首徽标条（`.examtags`）+ 本节开头的一览卡（`#examidx`，TOC 里也有入口）。
`ref` 的题号用 `_refdisp()` 转成 `Q2(g)`：`q`+数字+字母 → 自动加括号。

> ⚠️ 两个坑：
> ① `<a>` 不能套 `<a>`（一览卡的「页码行」是 `div`，里面两个独立链接，否则浏览器会把外层提前闭合）；
> ② 数据里写 LaTeX 必须写 `\\bar`、`\\gamma`（双反斜杠）——写成 `\bar` 会被 Python 吃掉成退格符，页面显示乱码。

覆盖率：**10 讲 / 99 条标注**——`final` 34 条（Topic 6/7/8，全部对应到 16 道练习题的具体小问）、
`mid` 23 条（Topic 1/2/3，对应期中练习 Key Concepts）、`must` 42 条（Topic 4/5/9/10 与其余高频页，我自己标的）。
来源分层是刻意的：**老师亲手划的只有 34 条，别把紫色当成考纲。**

## 十一、主页 `index.html` 怎么改

`python build_index.py` 生成，**不写死任何数据**——它现读三个来源：

| 来源 | 读什么 |
|---|---|
| `content_topic1..10.py` | 每讲标题、页数、`EXAM`（考点条数与内容） |
| `review_content.py` | 总复习九节的编号与标题 |
| `practice_content.py` | 练习四节、题目数量、`qid`（`q2g` 这种） |

所以加讲、加题、加考点之后，重跑一次首页自动跟上；文件大小也是现读 `os.path.getsize`。

### 页面上的四块

1. **三张主卡**：笔记 / 总复习 / 练习 —— 「读教材那一层 / 横向拉通那一层 / 动手那一层」，各自给三条要点和一个按钮。
2. **十讲地图**：按三块大陆分组，卡片右侧三个小圆点＝该讲的考点条数（红＝老师划的、橙＝期中、紫＝必背）。
3. **三条路线**：只剩两天 / 还有五到七天 / 从头补十天以上，每步都是可点的链接。
4. **考点总表**：99 条，四个筛选 chip ＋ 搜索框。搜 `挤出`、`稳态`、`T8`、`q2g` 都能命中；
   点「笔记 pXX」跳那一页，点 Q 号跳练习题。右下角实时显示「显示 n / 99 条」。

### 两个实现细节（改的时候别踩）

- **搜索不依赖 MathJax 渲染结果**：每行 `<tr>` 带一个 `data-s` 属性，存的是「去标签、去公式」的纯文本，
  JS 只在 `data-s` 上 `indexOf`。否则公式被渲染成 SVG 之后，中文检索会漏。
- **深色主题下不要把 `--accent / --red / --purple` 当背景色**：这几个变量在深色主题里是「高亮文字色」（浅蓝/浅粉），
  拿来当底就是浅底白字、看不清。彩色小元件（按钮、T 编号、chip、kind）一律写死深色值（`#2563eb / #b91c1c / #6d28d9`）。

### 返回总台

十讲笔记、总复习、练习页三个引擎的 hero 左上角各有一个「← 复习总台」胶囊按钮（`.home`），
所以从任何一页都能一键回到 `index.html`，不用靠浏览器后退。

### 自检（`build_index.py` 末尾）

跨文件链接会**真的去打开目标文件、检查锚点 id 是否存在**（不是只看文件在不在）。
改完内容重跑，最后一行应当是 `链接自检：0 坏链`。

## 十二、页面外壳 `ui_shell.py`（导航、进度、跳页）

四套页面以前各写各的，加一个公共部件要改四处、还容易改漏。现在公共部分统一放在
`ui_shell.py`，各自 `import ui_shell as U` 调三样东西：

```python
CSS += U.CSS                                        # 样式
UI_HTML = U.html(CURFILE, ORDER, paged=True, toc=True)   # 导航骨架
UI_JS   = U.JS(paged=True)                          # 进度条 / 跳页 / 上次位置
NEXTNAV = U.bottom(CURFILE, ORDER)                  # 页底「上一份 / 下一份」
```

### 页面上能看到什么

| 部件 | 位置 | 说明 |
|---|---|---|
| 左侧竖列 | 窗口 ≥1420 时贴正文左边 | `⌂ 总台`／`‹ T4`／`T6 ›`／`页码`／`☰ 目录`／`↑ 顶部` |
| 右下圆钮 | 窗口 <1420 | 同上，但收成 40px 圆钮，只留图标 |
| 顶部进度条 | 页面最顶端 3px | 蓝→紫渐变，随滚动填充 |
| 页码跳转 | 侧栏输入框 | 输 `37` 回车 → 跳到第 37 页（只十讲笔记有） |
| 上次读到 | 侧栏橙色虚线框 | 下次打开显示「上次 p37」，点一下接着看 |
| 页底翻页 | 每页最下方 | 上一份 / 下一份，最后一页显示「全部读完了 → 回总台」 |

### 四个实现细节（改的时候别踩）

1. **顺序在 `U.order(HERE)` 里定**：总台 → T1…T10 → 总复习 → 练习。加一讲不用改这里，
   它读的是各 `content_topicN.py` 头部的 `TOPIC_TITLE`（只读前 4 KB，不 import）。
2. **页码跳转只认 `#p1..#pN`**，`paged=True` 时才输出输入框。`window.__PGMAX` 由引擎传入，
   输超范围会提示「本讲只有 1 到 N 页」。
3. **上次位置用 `offsetTop` 判断，不用 `getBoundingClientRect`**。后者在滚动后可能读到旧布局，
   把页码记错（实测把 p12 记成 p2）。存 `localStorage['af5638_pos_<文件名>']`，按页各存各的。
4. **主题记忆在两处**：`setTheme()` 里存 `af5638_theme`，启动时读回来。以前只有主页存，
   笔记页刷新就弹回浅色。

### 目录在窄屏怎么办

右侧 `#toc` 卡片原本只在 ≥1520 才显示，1366/1440 的笔记本根本看不到。现在：
`☰ 目录` 按钮在 <1520 出现，点开是一个浮层抽屉；点条目、点空白处都会自动收起。
